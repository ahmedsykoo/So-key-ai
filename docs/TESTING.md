## 2) ما لم يُختبر (بصراحة تامة)

* ❌ **التشغيل على جهاز أندرويد أو محاكي**: لا يوجد `adb` ولا Android SDK ولا جهاز في هذه
  البيئة. لذلك **لم** يُتحقق من: الإقلاع الفعلي، أداء WebView، تناسق الواجهة بصريًا على
  شاشة حقيقية، منتقي الملفات SAF، مثبّت APK، الإشعارات، والإيماءات.
* ❌ **لقطة شاشة بصرية**: لا متصفح headless متاح، فالتقييم البصري يعتمد على مطابقة
  القيم المستخرجة من الصور المرجعية (`docs/UI-MAP.md`) وليس على مقارنة صور.
* ❌ **محادثة مع OmniRoute حقيقي**: لم يكن OmniRoute متاحًا في هذه البيئة؛ المسار مُختبَر
  بمزوّد وهمي يحاكي نفس صيغة OpenAI/SSE، ومسار CORS الأصلي (Java) مُراجَع لكنه يحتاج تجربة
  على الجهاز مع OmniRoute فعلي.
* ❌ **سير عمل GitHub Actions**: الملف مكتوب ويشغّل نفس الأوامر المُختبَرة محليًا، لكن الدفع
  به إلى المستودع لا يضمن أن الحساب مُفعِّل Actions؛ إن كان معطّلًا يعمل البناء المحلي كما هو.

## 3) كيف تعيد الاختبار محليًا

```bash
# كل شيء من الصفر
bash scripts/bootstrap-tools.sh                 # الأدوات (خارج Git)
python3 scripts/make-assets.py                  # الأيقونات من الشعار
cd tools/ui-smoke && npm install && node smoke.mjs && node csscheck.mjs && cd ../..
bash scripts/build-apk.sh --clean               # → artifacts/so-key-ai-1.0.0-debug.apk
```

## 4) قائمة فحص سريعة على الجهاز (يدويًا)

1. التثبيت ثم الإقلاع: تظهر الواجهة العربية الداكنة بالشعار الجديد.
2. تبديل اللغة ← English: تنقلب الواجهة LTR وتبقى سليمة.
3. المظهر ← اختر Neon ثم Terminal: يتغيّر كل شيء فورًا ويبقى بعد إعادة التشغيل.
4. المظهر ← تحجيم النص 130%: يكبر كل النص دون كسر التخطيط.
5. المظهر ← استيراد خط `.ttf` عربي: يتغيّر خط الواجهة فورًا ويُحفظ في مساحة التطبيق.
6. الإعدادات ← OmniRoute ← اختبار: «متصل» + قائمة نماذج.
7. محادثة جديدة: يظهر الرد تدريجيًا (بث)، ويظهر عدد التوكن أسفل الرد.
8. الطرفية: `help`, `ls`, `echo مرحبا > notes.txt`, `cat notes.txt`.
9. الملفات: إنشاء مجلد، كتابة ملف، مشاركته عبر مشاركة النظام.
10. سير العمل: تشغيل «تقرير الحالة الأسبوعي» ← يظهر إشعار الخدمة الأمامية، ثم تقرير في `reports/`.
11. زر الرجوع: يرجع من أي شاشة إلى الرئيسية، ثم يخرج من التطبيق.
